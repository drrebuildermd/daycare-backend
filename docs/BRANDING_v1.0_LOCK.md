## 코드에서 어디를 건드리면 되는가

### 색

`src/theme.js` 에서 가져다 쓴다. 화면 파일에 새 색을 만들지 않는다.

| 역할 | 값 |
|---|---|
| Primary action | Deep Navy `#0D2540` |
| 최적화·경로·내비게이션 | Teal `#0BA38E` |
| 성공/완료 | Green `#3BB273` (배경 `#E9F7EF`, 글자 `#237B4B`) |
| 보조/정보 | Mint `#6ED6C1`, Soft Gray `#F2F4F7` |
| 주의 | `#F2B84B` (배경 `#FEF6E7`, 글자 `#8A6100`) |
| 오류 | `#D64545` |
| 본문/보조 글자 | `#0D2540` / `#667085` |
| 선 | `#E4E7EC` |

작은 글자를 Teal 로 쓸 때 주의. `#0BA38E` 는 흰 바탕에서 대비가 3.16:1 로
모자란다. 진한 `#07705F` 를 쓰면 6.01:1 이다.

### 글자

**`src/ui/Text.js` 와 `src/ui/TextInput.js` 를 쓴다.** `react-native` 의
`Text`/`TextInput` 을 직접 가져오지 않는다.

안드로이드는 굵기마다 폰트 패밀리가 따로다. `fontWeight: '700'` 만 줘서는
굵어지지 않는다. 그 변환을 저 두 파일이 혼자 맡는다. 화면 코드는 지금처럼
`fontWeight` 만 쓰면 된다.

폰트는 `app.json` 의 `expo-font` 플러그인이 네이티브에 심고, 웹은
`src/ui/loadFonts.web.js` 가 따로 불러온다. 플랫폼 분기 덕에 TTF 가 두 벌
실리지 않는다. 실행 중에 등록하는 방식으로 되돌리지 말 것 —
실기기에서 일부 화면만 시스템 글꼴로 나오는 일이 있었다.

넣어둔 굵기는 Regular / Medium / SemiBold / Bold 네 종뿐이다.
800, 900 은 Bold 로 모인다.

### 아이콘

**`src/ui/Icon.js` 를 쓴다. 이모지를 UI 에 쓰지 않는다.**

MaterialCommunityIcons 한 세트만 쓴다. 세트를 섞으면 굵기와 모서리가 달라
화면마다 다른 앱처럼 보이고, 세트마다 폰트가 따로 실려 용량도 는다.

이름은 그림이 아니라 뜻으로 짓는다 (`navigate`, `boarded`, `center`, `home`).
아이콘을 갈아끼워도 화면 코드를 안 고치기 위해서다.

### 간격과 모서리

`space` (4 / 8 / 12 / 16 / 24 / 32), `radius` (8 / 12 / 16 / 999).

### 상태칩

배경 + 글자 (+ 필요하면 아이콘). `Accordion` 의 `badges` 로 넘긴다.

```js
badges={[
  { label: '자차 송영', icon: 'home', tone: 'warning' },
  { label: '확인 대기', icon: 'waiting', tone: 'default' },
]}
```

배지는 제목 아랫줄에 놓는다. 같은 줄에 두면 배지가 늘어날 때마다
차량번호와 기사님 이름이 잘려나간다.

### 버튼 위계

| 역할 | 생김새 |
|---|---|
| Primary | Deep Navy 채움 + 흰 글자 |
| Secondary | 흰 배경 + `#E4E7EC` 테두리 + Deep Navy 글자 |
| 결과/상태 카드 | 흰 카드 + 왼쪽 Teal 띠. 버튼처럼 보이면 안 된다 |

## 실기기에서 데인 것들

브라우저에서 안 보이던 것들이다. 화면을 새로 만들 때 같은 함정을 밟지 말 것.

**안드로이드는 화면 끝까지 앱이 그려진다(edge-to-edge).**
`react-native` 의 `SafeAreaView` 는 안드로이드에서 아무 일도 하지 않는다.
`react-native-safe-area-context` 의 `useSafeAreaInsets()` 로 실제 여백을 받는다.
브라우저에서는 이 값이 항상 0 이라 검증되지 않는다.

**가로로 늘어선 줄에서는 축소 규칙을 명시한다.**
글자 쪽에 `flex: 1, minWidth: 0` + `numberOfLines`, 버튼 쪽에 `flexShrink: 0`.
안 그러면 긴 이름이 들어왔을 때 오른쪽 버튼이 화면 밖으로 밀린다.

**화면에 떠 있는 버튼은 스크롤 끝을 그만큼 비운다.**
`App.js` 의 `ctaClearance` 가 그 계산이다.
`onLayout` 으로 재려 하지 말 것 — 웹에서 0 이 돌아온다.

**주소는 두 줄까지 보여준다.** 기사님에게 출발지는 운행 정보다.
배지와 한 줄을 나눠 쓰게 하면 주소에 남는 폭이 130px 남짓이 된다.

## 손대지 않기로 한 것

앱 아이콘, M-route 심볼, 스플래시, 관리자 헤더, ModeGate 구성,
관리자 현황 카드, 상태칩 구조, 기사님 화면의 큰 버튼 3개.

`frontend/tools/make_brand_assets.py` 가 아이콘·스플래시를 만든다.
패키지가 준 PNG 를 그대로 쓰지 않은 이유가 그 파일 주석에 있다.
심볼을 다시 뽑아야 하면 이 스크립트를 고쳐 쓴다. 손으로 그리지 않는다.
